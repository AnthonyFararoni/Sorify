First public release of Sorify: local speech-to-text for audio and video files on Windows, built on OpenAI Whisper.

**Download `Sorify-Setup-1.0.0.exe` below.** Windows 10/11 64-bit, installs for the current user without administrator rights. SmartScreen shows "Windows protected your PC" because the installer is not code-signed yet: click *More info → Run anyway*. Verify the file with `certutil -hashfile Sorify-Setup-1.0.0.exe SHA256` against `SHA256SUMS.txt`.

## What you get

- Drag-and-drop queue for files and folders, live transcript while decoding, per-file language and timing.
- Every Whisper model from `tiny` to `large-v3` and `turbo`; *Auto* picks `turbo` on an NVIDIA GPU and `base` on the CPU.
- 99 languages with auto-detection, *Translate to English*.
- Text paragraphs, timestamped text, SRT, VTT, TSV and JSON; save next to each file or into one folder.
- Beam search / fast decoding, word-level timestamps, subtitle line width, vocabulary prompt, context switch.
- *Transcribe with Sorify* in Explorer's right-click menu; `sorify` command for batch jobs.
- Built-in updater: release notes, *Update now / Remind me later / Skip this version*, SHA-256 verified downloads.
- Private: files never leave your PC.

## Setup downloads

After copying the app (50 MB), Setup downloads PyTorch (about 2 GB for the GPU build, 120 MB for the CPU build), Whisper and ffmpeg (80 MB) into Sorify's private runtime. The first transcription downloads the speech model (`turbo` 1.5 GB, `base` 140 MB).
